# Example manifests

This repo doesn't own a deployment pipeline — it publishes an image, nothing here gets
applied automatically. These manifests are a **worked example** of the Pod described in
the root [README](../../README.md#deployment): copy what you need into your own
cluster-config repo, replace every `REPLACE_*` placeholder, and adapt names/namespaces/
resource limits to your environment.

See the root README's "Deployment" section for the full configure-and-deploy walkthrough.
