# Security Policy

## Supported versions

This project has no releases or tags. The only supported version is the current
`main`, fixes are made there, and nothing is backported.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on
this repository, or go straight to [the advisory form](../../security/advisories/new). That opens a private security advisory, visible to this
repository's maintainers and to GitHub — not publicly.

Please do not open a public issue for a security problem.

Especially in scope is anything that lets repository content reach the published
site when the build was not meant to expose it, or that lets the polled
repository influence the host beyond the build output.

## What to expect

This is a personally maintained project with a single maintainer. Response is
best effort, not a service commitment. Expect an acknowledgement before a fix,
and no fixed timeline for either.
