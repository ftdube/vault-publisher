# Security Policy

## Supported versions

This project has no releases or tags. The only supported version is the current
`main`, fixes are made there, and nothing is backported.

## Reporting a vulnerability

Report it privately through GitHub: **Security -> Report a vulnerability** on this
repository. That opens a private advisory visible only to the maintainer.

Please do not open a public issue for a security problem.

Especially in scope: anything that lets repository content reach the published
site that the build was not meant to expose, or that lets the polled repository
influence the host beyond the build output.

## What to expect

This is a personally maintained project with a single maintainer. Response is
best effort, not a service commitment. Expect an acknowledgement before a fix,
and no fixed timeline for either.
